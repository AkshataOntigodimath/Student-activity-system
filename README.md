# Student-activity-system
🎓 Student Activity System

A web-based Student Activity Management System designed to streamline communication and activity management between students, teachers, parents, and administrators. The system provides role-based dashboards to manage events, registrations, attendance, student activities, and reports through a centralized platform.

🚀 Key Features

- 🔐 Role-Based Login – Separate access for Admin, Teacher, Student, and Parent.
- 👨‍💼 Admin Module – Manage users, activities, events, and overall system information.
- 👩‍🏫 Teacher Module – Create and manage events, registrations, attendance, and student activity reports.
- 🎓 Student Module – View activities and events, register for events, and track participation.
- 👨‍👩‍👧 Parent Module – Monitor student activities, participation, attendance, and related information.
- 📅 Event Management – Create, update, and manage student activities and events.
- 📝 Event Registration – Students can register for available activities.
- ✅ Attendance Management – Teachers can record and manage student attendance.
- 📊 Reports – View activity and participation details in an organized format.
- 🏆 Certificate Management – Support for managing student participation certificates.
- 📱 Responsive Interface – Designed to work across different screen sizes.
- 🎨 User-Friendly UI – Clean and structured interface with role-specific dashboards.

💡 Project Objective

The main objective of this project is to digitize student activity management and reduce manual work involved in maintaining event registrations, attendance, participation records, and communication between students, teachers, and parents.
